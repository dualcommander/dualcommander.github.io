User manual

Browse in one pane, choose a destination in the other. This guide covers everyday file management, settings, and connecting your favourite editor and terminal.

Shortcut key: Mod means Cmd on macOS and Ctrl on Windows/Linux. If your keyboard uses function keys for media controls, you may need Fn too.

Your first copy

  1. Open your source folder in the left pane. Double-click folders, or select one and press Enter.
  2. Open your destination folder in the right pane. Click the path field, enter a folder path, then press Enter.
  3. Click a source file in the left pane. For several files, mark each with Space or Mod+click.
  4. Press F5 or click F5 Copy. Check the target path, then confirm Copy.

Copy/move dialogs start with the other pane’s folder as the target. Check that path before confirming. Background operations show progress and cancellation controls.

Pane tour

Both panes have the same controls. Click inside a pane to make it active; Tab switches sides. The screenshot shows Brief view on the left and Detailed view on the right.

  1. Volumes and free spaceThe top-left dropdown selects a mounted drive or volume. The top-right value shows free space for that pane’s filesystem.
  2. Navigation and pathHome opens your home folder; the up arrow goes to the parent. Enter a path in the field and press Enter. The .. row, Backspace, or Mod+↑ also goes up.
  3. Favourite foldersThe star adds/removes the current folder. The adjacent dropdown opens saved favourites, shared between both panes.
  4. Brief or DetailedThe view button toggles this pane’s layout. Its icon shows the view you can switch to. Brief emphasises names; Detailed also shows size, modified date, and attributes. Use Mod+1 / 2 for the active pane.
  5. Sort headersClick Name, Size, or Date to sort; click again to reverse. The triangle shows direction. Sorting works in both views.
  6. Cursor versus marksClick sets the cursor; double-click or Enter opens. Marked names use a distinct colour (red here). Space/Insert or Mod+click toggles marks; Shift+click marks a range. Copy, move, and delete use marks, or the cursor item if none are marked.
  7. Status and selection totalsWithout marks, the bottom line describes the cursor item. With marks, it shows selected size and file/folder counts. Space also requests recursive folder size; large folders take time to count.
  8. Action barButtons act on the active pane, just like their F-keys. Use Edit, Copy, Move, MkDir, Delete, Terminal, or Quit. Copy/move default to the other pane’s folder.

Mod+U swaps panes; Mod+E opens the active folder in the other pane. Folder changes refresh automatically; Ctrl+R (also Cmd+R on macOS) reloads while preserving cursor and marks.

Right-click an item for Open, OS-specific Open With / Get Info or Properties, reveal, and copy path. The application Menu key also opens the cursor item’s context menu.

Deletion safety: Keep “Move deleted files to Trash” enabled unless you intend permanent deletion. With it disabled, delete removes files permanently rather than sending them to Trash/Recycle Bin.

Settings tour

Open Settings with Mod+, or the application menu (DualCommander on macOS; File on Windows/Linux). Changes save automatically; there is no Save button. Invalid command lists are not saved.

  1. AppearanceTheme follows the system or uses light/dark. Density chooses standard or compact file rows. Font size adjusts file-list text; use larger text for readability or compact rows to fit more files.
  2. File viewsChoose Brief/Detailed separately for left and right. Show hidden files affects both panes; Mod+Shift+. toggles it while browsing.
  3. File deletionMove deleted files to Trash is enabled by default. Disabling it makes deletion permanent.
  4. ArchivesBrowse archives in DualCommander opens supported archives like folders. Turn it off to use the OS-associated application instead. Browsing does not enable archive editing.
  5. External applicationsOverride Show in file manager, Open folder in terminal, and Edit file (F4); leave these fields blank to restore their OS defaults. Compare files uses the cursor file in each pane; Compare folder contents uses the current pane folders. Both comparison fields require a configured tool, such as ["meld", "{left}", "{right}"]; blank disables comparison. This example requires Meld on DualCommander’s PATH; if it works only in Terminal, use its absolute executable path as described in Troubleshooting external commands. Configure your tool’s flags for recursive folder-content comparison. See the command rules and examples below.

Custom command rules

Paste a complete JSON list into the relevant Settings field: executable first, then one string per argument. Do not paste a shell command line.

["code", "--wait", "{path}"]
  • {path} becomes the selected item’s full path. For F4, it is the file to edit.
  • {dir} becomes the active pane’s folder. Commands also start with that working directory.
  • For comparison commands, {left} and {right} become the cursor files or current folders in the left and right panes. Use both placeholders; comparison has no OS default.
  • Keep each path as one argument; spaces are preserved. JSON strings need double quotes, and Windows backslashes must be doubled.
  • No shell is used: ~, $HOME, %LOCALAPPDATA%, pipes, and redirects do not expand. Use an actual absolute executable path if the command is not on the app’s PATH.

Use trusted programs only. Custom commands launch local software with your user permissions. JSON validation checks syntax, not whether a program exists or whether its arguments are safe.

Use an alternative editor

  1. Install your editor, then open Settings → External applications → Edit file (F4).
  2. Paste one command below, adapting executable paths to your installation.
  3. Close Settings, select a regular text file, then press F4. Save in the external editor as usual.

Enter still uses the file’s OS association; changing F4 does not change that association. Leave the field blank for macOS’s default text editor, Windows Notepad, or Linux’s xdg-open association.

macOS — Visual Studio Code

If code is on the app’s PATH, use the command above. VS Code’s Command Palette offers Shell Command: Install 'code' command in PATH. Apps launched from Finder may have a different PATH than your shell. With VS Code installed in Applications, use its executable directly:

["/Applications/Visual Studio Code.app/Contents/Resources/app/bin/code", "--wait", "{path}"]

Or launch the app by its registered name, without relying on code:

["open", "-a", "Visual Studio Code", "{path}"]

Windows — Visual Studio Code or Notepad++

Use the actual Code.exe location. This example is a per-user VS Code installation; replace Alice with your Windows account directory. Use the executable rather than the code.cmd shell wrapper.

["C:\\Users\\Alice\\AppData\\Local\\Programs\\Microsoft VS Code\\Code.exe", "--wait", "{path}"]
["C:\\Program Files\\Notepad++\\notepad++.exe", "{path}"]

Linux — Visual Studio Code or Kate

These commands require the editor’s launcher on PATH. If needed, replace the first string with its installed absolute path.

["code", "--wait", "{path}"]
["kate", "{path}"]

--wait tells VS Code’s launcher to wait for the file to close; DualCommander launches it asynchronously, so browsing stays available. Other editors use their own flags.

Open in terminal

Set Settings → External applications → Open folder in terminal. Activate a normal filesystem folder, then press F9 or click F9 Terminal. The command uses that pane’s folder, regardless of the cursor item.

macOS — iTerm

With iTerm installed, paste:

["open", "-na", "ITerm", "{dir}"]

open launches the named app; -n requests a new instance and -a chooses the application. If your installation is not found by name, use its actual app bundle path:

["open", "-na", "/Applications/iTerm.app", "{dir}"]

For Apple Terminal (also the blank-field default):

["open", "-a", "Terminal", "{dir}"]

Windows — Windows Terminal or PowerShell

Windows Terminal needs wt.exe available through PATH / its app execution alias. -d chooses the starting folder:

["wt.exe", "-d", "{dir}"]

PowerShell inherits the active folder as its working directory. This is the blank-field default:

["powershell.exe", "-NoExit"]

Linux — GNOME Terminal, Konsole, or kitty

Choose an installed terminal. Explicit directory flags also work when a terminal reuses an existing process:

["gnome-terminal", "--working-directory={dir}"]
["konsole", "--workdir", "{dir}"]
["kitty", "--directory", "{dir}"]

Leaving the field blank auto-detects an installed terminal, starting with x-terminal-emulator. If launch fails or opens the wrong folder, choose an explicit command supported by your terminal version.

Troubleshooting external commands

  • Invalid list: use double quotes, no trailing comma, and one JSON string per argument.
  • Executable not found: install the app or supply its full path. A launcher working in your shell may not be on DualCommander’s PATH.
  • Wrong folder: check which pane is active and whether the terminal accepts the directory flag. Custom startup profiles can override the starting folder.
  • Restore defaults: clear the entire field. Reveal, terminal, and editor fields use the OS default; comparison fields become disabled. No restart is needed.

macOS: command works in Terminal, but not in DualCommander. Apps launched from Finder or the Dock do not necessarily inherit your shell’s PATH or shell startup files. An error such as exec: "meld": executable file not found in $PATH can occur even when Meld is installed and works in Terminal. This also applies to Homebrew-installed editors, terminals, and other comparison tools.

In Terminal, find the executable:

command -v meld

Copy the absolute path returned, then replace only the first string in the comparison command. For example, if the result is /opt/homebrew/bin/meld, paste this into Compare files or Compare folder contents:

["/opt/homebrew/bin/meld", "{left}", "{right}"]

Homebrew commonly uses /opt/homebrew/bin/meld on Apple Silicon and /usr/local/bin/meld on Intel Macs, but use your actual result, not an assumed location. If command -v returns nothing, install the tool or locate its executable first. If it reports a shell alias or function, use the actual executable instead. Do not paste command -v meld, $(command -v meld), ~, or $HOME into the JSON command: DualCommander does not run a shell or expand them. Changes save automatically; retry comparison without restarting.

Browse archives safely

With archive browsing enabled, Enter or double-click opens ZIP, TAR, 7z, RAR, compressed TAR, and supported single-file compression formats such as gzip, bzip2, XZ, and Zstandard. Password-protected ZIP, 7z, and RAR are supported.

Archives are read-only. Copy/move involving archive folders is not supported; use an external extraction tool. Nested archives are not browsed in-pane. Opening a member creates a temporary copy (up to 256 MiB), removed on exit. Editing that copy does not update the archive.

DEB and RPM packages open with their OS-associated app, which may launch an installer. Use an external tool if you only want to inspect them.

Saved settings and sharing configuration

DualCommander stores configuration under ~/.dualcommander/ in your home folder (on Windows, normally C:\Users\YourName\.dualcommander\):

  • settings.json: appearance, pane views, hidden files, deletion/archive behaviour, and external commands.
  • state.json: pane paths, active pane, sorting, and window size.
  • favourites.json: shared starred folder paths.

Use the dialog for routine changes. Close DualCommander before editing these files by hand; manual changes load on the next start. Invalid JSON or wrong value types stop startup without overwriting the file.

~/.dualcommander/
├── settings.json     Appearance, behaviour, and external apps; share this first
├── favourites.json   Starred folders; adapt paths on each machine
└── state.json        Last session; usually keep local

settings.json example

This sample uses OS-default reveal, terminal, and editor apps, with comparison disabled. A command is stored as a string containing a JSON argument list, not as an array. For example, VS Code is "editorCommand": "[\"code\",\"--wait\",\"{path}\"]". Use the commands from the editor and terminal sections above, escaping their double quotes when placing them inside this file.

{
  "appearance": { "theme": "system", "density": "standard", "fontSize": "medium" },
  "views": {
    "left": { "brief": true },
    "right": { "brief": false },
    "showHidden": false
  },
  "deletion": { "moveToTrash": true },
  "archives": { "browse": true },
  "externalApplications": {
    "revealCommand": "",
    "terminalCommand": "",
    "editorCommand": "",
    "compareFilesCommand": "",
    "compareFoldersCommand": ""
  }
}

favourites.json example

A plain array of absolute folder paths. Replace these sample paths with folders that exist on your machine. For Windows, use escaped backslashes such as "C:\\Users\\Alex\\Documents". An empty list is [].

[
  "/Users/alex/Documents",
  "/Users/alex/Projects"
]

state.json example

Session state is separate from reusable settings. This minimal example restores the active pane, folders, and window size; sorting is also saved here by the app. Keep the app-generated sort values when copying a real session.

{
  "pane": {
    "active": "left",
    "left": { "path": "/Users/alex/Documents" },
    "right": { "path": "/Users/alex/Downloads" }
  },
  "window": { "width": 1100, "height": 700 }
}

Move configuration to another machine

  1. Quit DualCommander on both machines so pending changes are saved and copied files cannot be overwritten by a running instance.
  2. Back up the destination’s .dualcommander folder before replacing anything.
  3. Create .dualcommander inside the destination user’s home folder if needed. Copy settings.json there to share appearance and behaviour. Copy favourites.json only if you also want the starred folders.
  4. Normally leave the destination’s state.json alone. Copy it only to transfer the last session, then change pane paths for the destination machine.
  5. Update favourites and external commands for the destination OS, username, installed apps, and executable paths. Blank reveal, terminal, and editor commands use OS defaults; blank comparison commands disable comparison. macOS commands such as open will not work on Windows or Linux.
  6. Start DualCommander and check both panes, favourites, editor, and terminal. If a config error prevents startup, fix the reported file or restore its backup while the app is closed.

Sync tip: distribute a copy of settings.json with your dotfiles or a private sync folder; install it while DualCommander is closed. There is no live reload or multi-process merge. Avoid simultaneous writes from multiple machines, and keep machine-specific state.json out of shared sync. Review paths and commands before publishing configuration: they can reveal usernames and private folder names.
