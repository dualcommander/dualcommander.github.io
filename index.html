Familiar tools. Focused workflow.

Files side by side

Copy, move, rename, and delete across two panes, with background progress and cancellation. Compare source and target details before choosing Skip, Overwrite, or applying either choice to all conflicts in that operation. Deletions use Trash or Recycle Bin by default.

Keyboard first

Switch panes with Tab. Copy with F5, move with F6, create files with Shift+F4, and create folders with F7. Mark files individually, as a range, or by name pattern; navigate back and forward through each pane’s folder history with Cmd/Ctrl+Left and Right.

Browse, extract, and create archives

Browse ZIP/ZIPX, TAR, 7z, RAR, compressed files, and CPIO, RPM, and DEB contents. Copy selected archive files or folders out with F5. Create ZIP, TAR, TAR.GZ, TAR.BZ2, TAR.XZ, or TAR.ZST with Alt+F5, with optional AES-256 passwords for ZIP. Existing archives stay read-only.

At home on your OS

Copy and paste files between DualCommander and your OS file manager. Open files in default apps, edit externally, reveal files, or launch a terminal. Configure external tools to compare files or folder contents. Right-click for Open With and Get Info on macOS, or Open With and Properties on Windows.

Your view, remembered

Brief and detailed views, sorting, shared favourite folders, light and dark themes, adjustable density, and font sizes. Pane paths, divider position, and window state persist. Choose from 30 interface languages in Settings; restart to apply.

Find files, keep browsing

Search by name or content, follow the current search path, and cancel when needed. Folder changes refresh automatically through native OS notifications. Switch mounted volumes, swap panes, or open the same folder on both sides.

Get DualCommander

Get it from Microsoft Store Download from GitHub Releases

For Windows, get the published app from Microsoft Store. Packages for all platforms are also available on GitHub Releases.

macOS with Homebrew:

brew install --cask dualcommander/tap/dualcommander

Version 0.2.0 is unsigned, so Gatekeeper may block its first launch. If you trust this release, try opening DualCommander, then open System Settings → Privacy & Security and choose Open Anyway. Do not remove quarantine attributes with xattr.

Unreleased builds — try changes not yet released; may be unstable. Download artifacts from successful builds (GitHub sign-in required).
Build locally — compile from source using the development guide.

Platform requirements

  • macOS: Apple Silicon (arm64) and Intel (amd64), as DMG or ZIP. Open the DMG and drag DualCommander into Applications.
  • Windows: x64 (amd64) and ARM64. For ZIP downloads, extract the entire package and run the top-level DualCommander.exe; keep the bundled software rendering files.
  • Linux: amd64 and arm64, as DEB, RPM, Arch Linux (.pkg.tar.zst), tar.xz, or Snap. Native packages require a compatible glibc and a desktop session with OpenGL support; system graphics libraries are not bundled.

Linux package dependencies reflect the build runner’s glibc version; older distributions may need a local build. See the Snap installation guide for installation and trust requirements.

Signing depends on the release configuration; do not assume GitHub downloads are signed or notarized. Your OS may show security warnings. Download only from the project repository or the Microsoft Store listing above, and review those warnings before running.
